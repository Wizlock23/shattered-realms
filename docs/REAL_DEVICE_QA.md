- [ ] Adventure dialogue → battle → result → rewards loop completes.
- [ ] Behemoth Phase 2 triggers at <= 50% HP.
- [ ] Collection filters scroll/tap correctly.

- [ ] Test Airplane Mode; current alpha should still play.
