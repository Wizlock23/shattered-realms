# Privacy Policy Draft — Mobile Alpha (internal draft, not legal advice)

**The Shattered Realms** Mobile Alpha currently stores game progress locally on the device. This alpha does not include account registration, advertising, analytics SDKs, cloud synchronization, third-party login, or real-money purchases.

For the current private alpha, the game stores information such as collection state, saved decks, campaign progress, faction mastery, quests, Gold, and Shard Dust in local device storage. This information is not transmitted to a Shattered Realms server because no production backend is connected yet.

Before TestFlight/public release, this policy must be updated to accurately describe every production service added, including authentication, cloud saves, analytics/crash reporting, purchases, customer support, multiplayer, and any other data processing. It should also include operator identity/contact information, retention/deletion practices, age-related handling, regional rights, and an effective date.
